Machine Learning

Predicción de Churn & Estrategia de Retención

Modelo clasificador LightGBM con optimización bayesiana para identificar clientes con alto riesgo de abandono. Se calibró el umbral de corte según la matriz de costes y beneficios de la campaña comercial para maximizar el ROI de retención.

Impacto: Recall del 84% en el decil superior de riesgo, estimando una reducción del 12% en cancelaciones evitables.
Python LightGBM SHAP Scikit-Learn
End-to-End / API

API de Tasación Inmobiliaria & App Interactiva

Pipeline completo de predicción de precios inmobiliarios. Modelo serializado servido mediante una API REST en FastAPI con esquemas de validación Pydantic, contenedor Dockerizado e interfaz interactiva para usuarios finales en Streamlit.

Arquitectura: Dockerfile optimizado multi-stage con tiempos de inferencia <45ms por solicitud.
FastAPI Docker Streamlit XGBoost

Extracción y Tendencias del Mercado Tech

Scraper asíncrono para ingesta periódica de vacantes tecnológicas. Pipeline ETL automatizado con almacenamiento en base de datos relacional y panel analítico para explorar la correlación entre stacks técnicos y rangos salariales.

Pipeline: Ingesta automatizada con GitHub Actions y procesamiento rápido sobre datasets tabulares con Polars.

Forecasting

Previsión de Demanda Retail Multitienda

Predicción de ventas a 30 días vista utilizando técnicas de series temporales jerárquicas y validación temporal con ventanas rodantes (*rolling-window backtesting*), superando baselines estadísticos clásicos.

Métrica: WAPE reducido al 8.2% incorporando componentes de estacionalidad semanal y calendario de festivos.
