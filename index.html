Machine Learning

Predicción de Churn & Estrategia de Retención

Modelo clasificador LightGBM con optimización bayesiana para identificar clientes con alto riesgo de baja. Se redujo el coste por falso negativo calibrando el umbral de probabilidad hacia el ROI de la campaña de retención.

Impacto: Recall del 84% en el decil de mayor riesgo, proyectando un ahorro anual del 12% en bajas evitables.
Python LightGBM SHAP Scikit-Learn
End-to-End / API

API de Tasación Inmobiliaria & App Interactiva

Pipeline completo de estimación de precios inmobiliarios. Modelo serializado servido vía FastAPI con validación Pydantic, contenedor Docker y frontend interactivo en Streamlit.

Arquitectura: Dockerizado en Render + monitorización básica de latencia y deriva de predicción.
FastAPI Docker Streamlit XGBoost
Data Engineering & EDA

Extracción y Tendencias del Mercado Tech

Scraper asíncrono sobre ofertas de empleo en portales tech. Limpieza automatizada en SQLite y visualización interactiva de salarios vs. skills demandadas por región.

Volumen: +15.000 ofertas procesadas periódicamente mediante GitHub Actions.
Playwright SQLite Polars Plotly
Forecasting

Previsión de Demanda Retail Multitienda

Predicción de ventas a 30 días vista utilizando técnicas de series temporales jerárquicas y validación temporal rodante (*rolling window*), superando baselines estadísticos (ARIMA) en WAPE.

Métrica: WAPE reducido al 8.2% con ingeniería de estacionalidad y festivos.
Prophet Statsmodels Pandas
